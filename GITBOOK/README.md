# Introduction

Current release is [1.10](https://github.com/sazenice/FakeDeathBan/releases/tag/1.10)

Pre-Release version is **1.11-pre5**

Plugin is for versions **1.21.11-26.3**, [paper and its major forks][^1]

Dead players are not banned. They are switched to spectator mode and can watch the rest of the server, which suits scripted SMP servers where players would otherwise lose all engagement after dying.
